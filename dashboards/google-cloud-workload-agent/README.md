### Dashboards for Google Cloud Agent for Compute Workloads

#### Oracle

| Agent for Compute Workloads - Oracle Status Overview |
|:-----------------------------------------------------|
| Filename: [agent-for-compute-workloads-oracle-status-overview.json](agent-for-compute-workloads-oracle-status-overview.json) |
| This dashboard monitors Oracle Database instances running on Compute Engine VMs using metrics collected by [Google Cloud Agent for Compute Workloads](https://cloud.google.com/workload-manager/docs/evaluate/set-up-agent-for-oracle). It displays Average Active Sessions by Wait Class, Database memory usage (PGA and SGA components), Database time breakdown, Oracle agent health (`workload.googleapis.com/oracle/health`), and Compute Engine VM CPU utilization, Network Traffic, and Disk I/O. |
| Prerequisites: Install and configure Google Cloud Agent for Compute Workloads with Oracle metric collection enabled on your Compute Engine VM. See [Set up the agent for Oracle workloads](https://cloud.google.com/workload-manager/docs/evaluate/set-up-agent-for-oracle) for setup instructions. |
